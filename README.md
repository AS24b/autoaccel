# AutoAccel

Automated Design-Space Exploration and Multi-Objective Optimization of Energy-Efficient Arithmetic Accelerators.

## Project Status

Under development

## Initial Goal

Build an automated framework that can generate, verify, synthesize, and evaluate configurable arithmetic accelerator architectures.

## Initial Experimental Platform

Integer multiplication.

Initial architectures:
- Conventional multiplier
- Karatsuba multiplier

Initial parameters:
- 8-bit
- 16-bit
- 32-bit

Initial hardware metrics:
- Area
- Timing

## Planned Technologies

- SystemVerilog
- Python
- Yosys
- Verilator/other open-source simulator
- Jupyter Notebook

## Team

Two-person undergraduate ECE/VLSI team.
